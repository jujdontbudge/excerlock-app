# Home

Home receives a presentation model and emits navigation/action callbacks. The
lock, balance, condition region, and shortcuts keep stable geometry across
locked, unlocked, low, empty, and access-holiday states. Event completion is
shown in place; multiple pending earns aggregate into one transition and no
claim screen or confetti is used. The route adapter may emit one light local
haptic exactly when the lock changes from closed to open; that is the app's
sole physical-feedback exception. Balance/rule/condition sheets and nudge,
and last-call focus are deterministic local presentation state.
