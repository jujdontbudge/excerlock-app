# Sessions

Walking and gym screens render reducer-owned deterministic phases. Their status
copy always identifies sample behavior: no sensors, location, or health source
is accessed. Walking keeps access open while moving but explicitly retains
normal balance drain.

Active walking shows the applicable condition summary when one exists. Pause
and end are locally staged confirmations; ended sessions expose local detail
and lock-explanation sheets before any route callback runs. Timers and metrics
remain deterministic preview state and never invoke device services.
