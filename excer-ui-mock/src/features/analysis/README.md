# Analysis feature

This module composes the Analysis overview, trend and day detail, earning breakdown, milestone details, and aggregate-only share preview. Router adapters provide callbacks and any selected range/date/badge state.

Charts are visual summaries of sample fixtures. Every plotted control has a text summary, all heat-map cells and badges are pressable, and share/save actions only open labeled prototype previews. No user name, app name, gym, location, or raw health value appears in share content.

Trend detail exposes earned, spent, and reclaimed series plus a transactional comparison choice sheet. Notification recap entry forces the fresh local recap and its canonical share path. Badge routes expose locked/unlocked/new families; badge-specific route content remains called out separately in the `DESIGN.md` evidence ledger until the route parameter selects unique copy/art.
