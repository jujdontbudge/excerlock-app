# Condition builder

The builder is a full-screen gradient flow backed by a reducer-owned typed
path. New conditions move through activity category, earning method, optional
place, kind-specific configuration, and then one decision per screen. Event
conditions keep reward, daily cap, cooldown, repeatability, and active window
separate before artwork and the exact Home-card preview. State and rate paths
include only decisions that apply to them.

Choices start blank and saving is impossible until every required decision is
explicit. Edit mode hydrates and replaces the selected condition, with staged
enable/delete actions and confirmation at the route boundary. Rate conditions
expose no cap or claim control. Precision values use accessible steppers;
Back and Save preserve the existing draft/commit semantics.
