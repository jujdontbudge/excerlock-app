# Condition builder

The builder renders the reducer-owned typed path: catalog, optional place,
configuration, optional event reward, banner, and exact card preview. Economy
choices start blank and saving is impossible until every required choice is
explicit. Edit mode hydrates and replaces the selected condition, with staged
enable/delete actions and confirmation at the route boundary. Rate conditions
expose no cap or claim control. Precision edits intentionally use transactional
choice sheets and steppers instead of inertial wheel pickers; Cancel and Done
still preserve draft/commit semantics.
