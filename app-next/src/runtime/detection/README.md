# Detection runtime boundary

`DetectionService` is composed once above React navigation and can also be called by a module-scope background task. Raw motion and placement adapters retain native source timestamps and reduce into `detectionStore`; no Home-screen timer owns truth. `reconcileWake` consumes durable gym transitions and historical step deltas idempotently through a cursor. History credits targets only and never asserts current walking relief. `noteCoverageLost` invalidates transient live evidence after an unknown process/sensor gap.

Root composition supplies native providers, background-task registration, rule/window scheduling and enforcement reconciliation. The service deliberately imports neither shielding nor navigation. Placement thresholds remain the existing device-recorded classifier values; pickup latency remains a physical-device gate.
