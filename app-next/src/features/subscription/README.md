# Trial and paywall

Onboarding ends with the trial preview (S3c), the reminder screen (S3d, which asks for notifications) and this paywall; the old trial screens T1–T4 were retired. `PaywallSlot` supplies a local stand-in until Phase 2 mounts Adapty Paywall Builder. It serializes actions, presents an 800 ms busy state and reports cancel/error/not-found without granting access. Only the fake port changes entitlement.

Root route guards remove onboarding history at the paywall and protect setup/tabs by entitlement. A lapse while the app is open selects the in-app placement; a cold start that is already expired asks Home for the `winback` placement once per session (`winbackSession.ts`). The onboarding hard wall has no decline and no close (the old "Not now" was removed on September 23, 2026; `onboardingStore.winbackDeclined` is kept only so saved installs still load). A win-back load failure falls back to the placement the surface would otherwise have requested. `billingIssue` and `none` keep the in-app placement. Restore outcomes and placeholder offer notes are exposed only in the dev controls. Product prices remain dashes.
