# Sessions and shield preview

`HomeSheets` opens the shared walking or gym sheet. `WalkingSheet` displays the fake port’s phase, lease/grace countdown, verified steps and ending summary; minimizing preserves the session on Home. Treadmill framing uses the fake propped/handheld state. `CheckInSheet` validates presence through the Gym port and reports success without exposing individual blocked apps.

`ShieldPreview` consumes the pure `domain/shieldContent` contract. It is reachable from the developer menu. All scripts, placement, gym presence and progress are local; Phase 2 mounts the native adapters behind these ports.
