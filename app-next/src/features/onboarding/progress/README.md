# Progress introduction

O02 renders the approved progress composition using separate native gradient bars, an SVG trend curve, a highlighted point, and a native text badge. Bars rise in sequence, the curve draws on, and the badge floats gently. Reduced Motion uses fades and a complete curve without spatial loops. Copy lives in `src/content`; composition geometry and colors live in `illustrationTokens.welcome`.

The second-page dots provide the return action to O01. Get started advances to O03; sign-in and legal reading reuse the welcome footer.
