# Setup routes

After the paywall an entitled user lands on `setup/X1`, which runs `src/packages/setup/SetupRoute`: mandatory sign-in, then one screen for each permission the enabled Conditions need (ADRs 0043 and 0049). Not now applies to permission screens only; no Setup path opens Home before an explicit sign-in in this launch. Older installs saved on X3–X5 resume at the same flow. The same permission screens open without another sign-in at `app/permissions.tsx` after the launch gate is approved, from Home's reminder card and after a Condition that needs something new is saved or turned on.
